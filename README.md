# AI for Thin Films — MLP-Based Spectral Prediction and Data-Driven Design

Course project for the *Thin Film Technology* AI4S assignment.

Transfer-matrix method (TMM) + multilayer perceptron (MLP) surrogate model
for predicting the reflectance spectra of multilayer dielectric thin films
and accelerating antireflection coating design at a student-specific target
wavelength.

## Student-specific parameters

- Student name  → `曹攸然`
- Student number  → `2023276029`
- Student number (last 6 digits) → `seed = 276029`
- Last two digits `N = 29` → `lambda_target = 450 + 10 × (29 mod 31) = 740 nm`
- `design_seed = seed + 1 = 276030`

## Problem setup

| Item | Value |
| --- | --- |

| Thickness range | 40–180 nm per layer |

## Repository layout

- `tmm.py` — transfer-matrix method (vectorized reflectance computation)

## Reproduce all paper results

One command regenerates every number and figure in the paper:

```bash
python main.py
```

The pipeline and what it produces:

1. **TMM data generation** — 5000 thickness–spectrum pairs, fixed 4000/500/500 split (seed-controlled).
2. **MLP training** — 4-128-128-64-41, MSE, Adam; prints train/val/test MSE & RMSE (Fig. 4).
3. **Training-size study** — 500/1000/2000/4000; prints test RMSE (Fig. 6).
4. **Screening** — 10,000 candidates at 740 nm; prints Top-5 designs (Table 1, Fig. 7).
5. **Figures** — 8 PNG files written to `figures/`.
6. **`results.npz`** — all numbers needed for the paper tables (Top-5 thicknesses, MLP/TMM reflectance, training-size RMSE, loss history).

Paper figure/table ↔ script correspondence:

- Fig. 1–8 → `figures/fig1_workflow.png` … `fig8_failure.png`
- Table 1 (Top-5 designs) → `results.npz` keys `top5_thickness`, `top5_mlp_R`, `top5_tmm_R`
- test MSE / RMSE → printed in step [2], saved as `test_pred` in `results.npz`
- training-size RMSE → printed in step [3], saved as `size_results`

## Thin-film screening method

1. Generate 10,000 candidate thickness stacks with `design_seed = 276030`.
2. Predict the reflectance at `lambda_target = 740 nm` with the trained MLP.
3. Rank candidates by ascending predicted reflectance (antireflection goal), keep the Top 10.
4. Re-compute the true reflectance of the Top 10 with TMM and keep the Top 5.

## Key results (regenerated by `python main.py`)

- Final MLP test MSE = 4.0e-4 (RMSE ≈ 2.0e-2)
- Training-size effect (test RMSE): 5.6e-2 (500) → 3.6e-2 (1000) → 2.8e-2 (2000) → 2.0e-2 (4000)
- Best TMM-verified antireflection design at 740 nm: R = 1.4e-2
